# Issue tracker

Issues for this plugin are tracked as TaskNotes in the maintainer's vault (`Book Of Holding/TaskNotes/Tasks/`, one Markdown note per ticket), never in GitHub Issues. The full convention lives with the harness at `personality-chip/skills/setup-skills/issue-tracker-tasknotes.md`. This project's anchor is `[[Balamb Garden - Soul]]`: every ticket's first `projects` link.
